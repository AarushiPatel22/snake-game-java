## 📌 About The Project

This project is a modern version of the classic **Snake Game**, developed using **Core Java, Java Swing**.

The game provides an interactive desktop experience with smooth movement, real-time score updates, collision detection, pause functionality, restart options, and a clean dark-themed user interface.

It was built to practice important **Core Java concepts**, including object-oriented programming, event handling, GUI development, timers, and keyboard input.

---

## ✨ Features

🎮 **Interactive Gameplay**
- Smooth snake movement
- Arrow key controls
- Random food generation
- Snake grows after eating food

📊 **Score System**
- Live score tracking
- High score tracking

💥 **Collision Detection**
- Wall collision detection
- Self-collision detection
- Game Over screen

🎨 **Modern UI**
- Dark-themed interface
- Neon-style snake design
- Direction-based snake eyes
- Clean game board with grid layout
- Pause overlay
- Game Over overlay

⚙️ **Game Controls**
- Pause and resume gameplay
- Restart the game
- Return to the main menu

---

## 🕹️ Controls

| Key | Action |
|:---:|--------|
| ⬆️ | Move Up |
| ⬇️ | Move Down |
| ⬅️ | Move Left |
| ➡️ | Move Right |
| `SPACE` | Pause / Resume |
| `R` | Restart Game |
| `M` | Return to Main Menu |
